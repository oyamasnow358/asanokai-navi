# あさの かい ナビ（MieeL）

にっちょくが タブレットの ページを めくって、あさの かい・かえりの かいを すすめる アプリです（特別支援教育向け・iPad / iPhone、テレビに うつしても つかえます）。

## できること
- **あさの かい**：はじめの あいさつ → ひづけ → **きょうは なんの ひ**（しゅくじつ・ぎょうじ・きせつ。せいじんの ひ／うみの ひ なども じどう けいさん）→ てんき → けんこう かんさつ（1にんずつ なまえを よぶ）→ **おたんじょうび**（その ひの 子を じどうで おいわい）→ きょうの よてい → **きゅうしょくの こんだて** → めあて → **かかりの しごと** → ひとこと スピーチ → **こんげつの うた** → せんせいの おはなし → おわりの あいさつ（どれも オン／オフ・ならびかえ できる）
- **かえりの かい**：ふりかえり（たのしかった じかんを えらぶ）→ かかりの ほうこく → あしたの よてい → さようなら
- にっちょくが よむ セリフが 1ぎょうずつ ひかる。ことばが でにくい 子は 🔊 で アプリが かわりに いう
- にっちょくは ひが かわると つぎの 子に じどうで こうたい
- **じゅんび（せんせい）**：クラスの なかま（しゃしん・え・たんじょうび）、かかりの わりあて、こんげつの うた、ようびごとの じかんわり、すすめかたの じゅんばん・オン／オフ、めあて、スピーチの おだい。クラスは いくつでも
- **A4 プリント**：にっちょくの しんこう カード・じかんわり・けんこう かんさつ ひょう（1かげつ）
- 🏠 ボタンで いつでも さいしょへ（すすめて いる とちゅうは ながおし）

## こじんじょうほう
なまえ・しゃしん・けんこうの きろくは この たんまつの なかだけに ほぞん し、インターネットには おくりません。
